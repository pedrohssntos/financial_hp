# financial_hp
Planilha para simular o crescimento do patrimônio com aportes mensais, estimar a renda passiva com dividendos e sugerir como distribuir o aporte entre tipos de fundos conforme o perfil do investidor.  > ⚠️ **Aviso:** esta ferramenta é uma simulação educacional. Os resultados dependem das taxas informadas e não representam garantia de rentabilidade.
